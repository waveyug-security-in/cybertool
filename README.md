# 🛡️ CyberTool

*Free phishing URL & message scanner — built for Indian users.*

🌐 *Live Demo:* [waveyug.in/cybertool](https://waveyug.in/cybertool)

---

## ✨ Features

- 🎯 *Bank Phishing Detection* — SBI, HDFC, ICICI, Axis, Paytm, PhonePe
- 🇮🇳 *Indian Govt Scam Detection* — Parivahan, e-Challan, RTO, Income Tax
- 🔍 *Homoglyph Detection* — catches g00gle, micros0ft, paytm-secure
- 📱 *Multi-URL Scanning* — paste up to 10 links at once
- ☁️ *Cloud-Hosted Phishing* — detects Vercel, GitHub Pages, Netlify clones
- 🔒 *Zero False Positives* — verified on legit Indian bank URLs
- ⚡ *100% Offline* — no signup, no data leaves your browser
